# RightClickAssistant v1.2 验收记录

- 验收日期：2026-07-12
- 分支：`codex/v1.2-native-upgrade`
- 版本：`1.2.0`
- 环境：macOS 真机、Command Line Tools、Apple Silicon
- 范围：v1.2 原生体验、动作可靠性、健康诊断、更新、Homebrew Cask、发布门禁与文档

## 结论

当前工作树已通过可在本机执行的产品构建、严格并发编译、脚本、Cask、签名结构、DMG 和关键动作端到端验证。Finder 真实菜单、五个设置页面与系统深色模式均已重新截图并人工检查。

本轮端到端验证首先捕获到灰度 Alpha PNG 转 JPEG 失败。OSLog 将故障定位到 `NSImage -> TIFF -> NSBitmapImageRep` 中间层；转换器改为 ImageIO 直接转码并新增回归测试后，同一输入和完整 10 项跨进程验证均通过。

以下两项不能在当前机器上伪装为已通过：

1. `swift test` 在测试源码编译前被本机 CommandLineTools 的 `PackageDescription` arm64 ABI 链接错误阻塞。Core 已用 Swift 6 严格并发直接编译，关键模块另有原生 harness 与真机端到端验证；完整 XCTest 仍由含完整 Xcode 的 CI 执行。
2. 本机没有 Developer ID 与 Apple 公证凭据，因此未生成正式公证制品。标签发布工作流会在缺少证书或公证凭据时失败，不会降级发布 Ad-hoc 制品。

## 发布说明

仓库开发版本已经进入 `1.2.0`，但在创建并推送 `v1.2.0` 标签前，README 和 Cask 继续指向已发布且可校验的 `v1.1.1` 不可变制品。这避免把本地构建误写成线上稳定发布。

正式发布前还需在具备仓库 Secrets 的标签 CI 中看到签名、公证、stapler、制品哈希与 Release 上传全部成功；任何一步失败都必须阻止发布。
