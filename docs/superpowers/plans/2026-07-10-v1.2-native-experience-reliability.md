# RightClickAssistant v1.2 Native Experience And Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 RightClickAssistant 升级为默认简洁、专业能力按需开启，并修复测试隔离、异步动作确认、诊断真实性与发布供应链问题。

**Architecture:** 保留 Host + FinderSync + 文件队列主架构，在共享层增加可注入存储、版本化事件、单一动作注册和异步终态契约。SwiftUI 设置按用户任务拆页；FinderSync 继续只做快速过滤、渲染和事件投递，耗时工作全部由 Host Runner 执行。

**Tech Stack:** Swift 6、SwiftUI、AppKit、FinderSync、Foundation、CryptoKit、OSLog、XCTest、Bash、GitHub Actions、Homebrew Cask。

## Global Constraints

- 最低系统版本保持 macOS 13.0。
- 不引入第三方 Swift 依赖或后台遥测。
- 旧版 `SharedActionEvent`、`clipboard.json` 和 `config.json` 必须可读取。
- 高风险动作默认关闭，任何 profile 都不得批量开启高风险动作。
- FinderSync 菜单热路径不得新增同步网络、Process 或大文件 IO。
- 现有 Pending -> InFlight 原子 rename、Failed 隔离、双通道唤醒必须保留。
- 所有 XCTest 必须使用临时目录，禁止触碰真实 `~/Library/Containers`。
- 标签发布缺少 Developer ID 或公证凭据时必须失败，不得回退为 Ad-hoc 正式发布。
- 每项任务完成后运行对应验证并使用中文 Conventional Commit。

```swift
public enum ReloadChoice: Equatable, Sendable {
    case relaunchAppAndRestartFinder
    case restartFinderOnly
    case later
}

public struct ReloadOutcome: Equatable, Sendable {
    public let choice: ReloadChoice
    public let relaunchResult: SystemCommandResult?
    public let restartFinderResult: SystemCommandResult?

    public var isSuccess: Bool {
        switch choice {
        case .relaunchAppAndRestartFinder:
            return relaunchResult?.isSuccess == true && restartFinderResult?.isSuccess == true
        case .restartFinderOnly:
            return restartFinderResult?.isSuccess == true
        case .later:
            return true
        }
    }
}

public static func performReload(
    choice: ReloadChoice,
    bundleURL: URL,
    completion: @escaping @MainActor @Sendable (ReloadOutcome) -> Void
) {
    DispatchQueue.global(qos: .userInitiated).async {
        let outcome: ReloadOutcome
        switch choice {
        case .relaunchAppAndRestartFinder:
            let relaunch = relaunchAppForPermissionRefresh(bundleURL: bundleURL)
            let restart = relaunch.isSuccess ? restartFinderOnly() : nil
            outcome = ReloadOutcome(
                choice: choice,
                relaunchResult: relaunch,
                restartFinderResult: restart
            )
        case .restartFinderOnly:
            outcome = ReloadOutcome(
                choice: choice,
                relaunchResult: nil,
                restartFinderResult: restartFinderOnly()
            )
        case .later:
            outcome = ReloadOutcome(
                choice: choice,
                relaunchResult: nil,
                restartFinderResult: nil
            )
        }
        Task { @MainActor in
            completion(outcome)
        }
    }
}
```

Pass both refresh arguments. Remove the lifetime-long `.idleSystemSleepDisabled` activity from `AppDelegate`; the folder monitor and DistributedNotification remain the wake mechanisms. Mark queue-protected caches `@unchecked Sendable`, make Background runner closures `@Sendable`, and move HUD AppKit completion work into a `Task` explicitly isolated to `MainActor`. Respect `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`.
